# A Run makes one Contribution

Each Run does one thing within its Phase's Pattern: one plan of a Panel, one synthesis, one comment of a Discussion round, one review. Sofa moves the Pattern on as Runs finish, and an Agent taking part in several rounds gets a fresh Run each time, reading the earlier Contributions rather than remembering them. Every step is then a record of its own that a User can review afterwards, any Worker can take the next Run, and a round lost to a crash costs one Run, not the whole Phase.

## Considered Options

- **One long Run per Agent per Phase**, keeping its session through the Discussion rounds: more context carried over, but one session's state can't be reviewed step by step, moved to another Worker, or mixed with another vendor's agent.

## Consequences

- What an Agent needs from an earlier round must be in a Contribution, so Briefs ask Runs to write down their reasoning, not only their conclusion.
